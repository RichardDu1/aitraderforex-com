### Forex VPS Latency Benchmarking Tool
This open-source Python tool automates the process of measuring latency from multiple VPS data centers to your broker's servers. It uses K-means clustering to group VPS regions by performance and recommends the best one. Ideal for traders using EAs or manual strategies that require low latency.
