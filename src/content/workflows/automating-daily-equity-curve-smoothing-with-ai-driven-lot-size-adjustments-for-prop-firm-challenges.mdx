## Step 3: Build the AI Lot Size Model

Create a Python script that:
- Fetches daily equity data from MT5 via `MetaTrader5` library.
- Trains a simple linear regression model to predict next day's equity change.
- Adjusts lot size inversely to predicted volatility: lower lot size when high drawdown expected, higher when stable.

```python
import MetaTrader5 as mt5
import pandas as pd
from sklearn.linear_model import LinearRegression
import numpy as np

# Initialize MT5
mt5.initialize()

# Get account info
account_info = mt5.account_info()
balance = account_info.balance

# Fetch daily equity history (last 30 days)
rates = mt5.copy_rates_from_pos("EURUSD", mt5.TIMEFRAME_D1, 0, 30)
df = pd.DataFrame(rates)
df['equity'] = balance + (df['close'] - df['open']) * 10000  # simplified

# Train model on equity changes
X = np.arange(len(df)).reshape(-1, 1)
y = df['equity'].pct_change().dropna().values
model = LinearRegression()
model.fit(X[:-1], y)

# Predict next change
pred_change = model.predict([[len(df)]])[0]

# Adjust lot size: base lot 0.01, scale by inverse of predicted absolute change
base_lot = 0.01
if abs(pred_change) > 0.02:  # high volatility
    lot = base_lot * 0.5
else:
    lot = base_lot * 1.2

print(f"Predicted change: {pred_change:.4f}, Lot size: {lot:.2f}")
```

## Step 4: Integrate with MT4 via File or API

Option A (File-based):
- Write lot size to a text file (`lot.txt`) in MT4's `Files` folder.
- MT4 EA reads the file every tick and sets lot size.

Option B (API):
- Use a REST API (e.g., Flask) to send lot size from Python to MT4 EA.
