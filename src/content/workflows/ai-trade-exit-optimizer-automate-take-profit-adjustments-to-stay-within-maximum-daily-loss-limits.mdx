## Overview

Prop firm challenges impose strict maximum daily loss rules. Manually adjusting take-profit (TP) levels to stay within limits is error-prone and time-consuming. This guide builds an AI-based trade exit optimizer using Python and OpenAI's API that monitors your account equity in real-time and automatically adjusts TP levels to prevent exceeding the daily loss limit while optimizing profit capture.

## Prerequisites

- **MetaTrader 5 (MT5)** account with a prop firm challenge (e.g., FTMO, MFF, The Funded Trader)
- **VPS** (e.g., Vultr, AWS EC2) running 24/7 with low latency
- **Python 3.8+** installed on VPS
- **OpenAI API key** (or any LLM API)
- Basic knowledge of Python and MT5

## Step 1: Set Up VPS and Install Dependencies

1. Deploy a VPS (e.g., Vultr $10/mo plan, Ubuntu 22.04).
2. SSH into VPS and install Python packages:
   ```bash
   pip install MetaTrader5 openai pandas numpy schedule
   ```
3. Install MT5 on VPS (headless mode) and log in to your prop firm account.

## Step 2: Build the AI Exit Optimizer Script

Create a Python script `ai_exit_optimizer.py`:

```python
import MetaTrader5 as mt5
import openai
import time
import json

# Configuration
MAX_DAILY_LOSS_PERCENT = 5  # e.g., 5% of starting balance
STARTING_BALANCE = 100000    # adjust to your challenge
openai.api_key = "your-api-key"

# Initialize MT5
if not mt5.initialize():
    print("MT5 init failed")
    quit()

def get_daily_pnl():
    account_info = mt5.account_info()
    equity = account_info.equity
    daily_pnl = equity - STARTING_BALANCE
    return daily_pnl, equity

def get_open_positions():
    positions = mt5.positions_get()
    return positions

def calculate_risk_remaining(daily_pnl):
    max_loss = STARTING_BALANCE * (MAX_DAILY_LOSS_PERCENT / 100)
    remaining_risk = max_loss - abs(daily_pnl) if daily_pnl < 0 else max_loss + daily_pnl
    return remaining_risk

def ai_adjust_tp(position, remaining_risk):
    prompt = f"""
    You are a Forex risk manager. A trader has an open position:
    Symbol: {position.symbol}
    Type: {'Buy' if position.type == 0 else 'Sell'}
    Volume: {position.volume}
    Current Price: {position.price_current}
    Open Price: {position.price_open}
    Current TP: {position.tp}
    Remaining daily loss buffer: ${remaining_risk:.2f}
    
    Suggest a new take-profit level that:
    - Ensures the trade does not cause daily loss limit breach if it reverses.
    - Maximizes profit potential given the remaining buffer.
    - Output only the price level as a number.
    """
    response = openai.ChatCompletion.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}],
        max_tokens=10
    )
    new_tp = float(response.choices[0].message.content.strip())
    return new_tp

def modify_tp(position, new_tp):
    request = {
        "action": mt5.TRADE_ACTION_SLTP,
        "position": position.ticket,
        "sl": position.sl,
        "tp": new_tp
    }
    result = mt5.order_send(request)
    return result

def main():
    while True:
        daily_pnl, equity = get_daily_pnl()
        remaining_risk = calculate_risk_remaining(daily_pnl)
        positions = get_open_positions()
        for pos in positions:
            new_tp = ai_adjust_tp(pos, remaining_risk)
            modify_tp(pos, new_tp)
            print(f"Adjusted TP for {pos.symbol} to {new_tp}")
        time.sleep(60)  # run every minute

if __name__ == "__main__":
    main()
```

## Step 3: Run the Script on VPS

1. Upload the script to VPS.
2. Run in background:
   ```bash
   nohup python3 ai_exit_optimizer.py &
   ```
3. Monitor logs: `tail -f nohup.out`

## Step 4: Test and Validate

- Run on a demo account first.
- Simulate losing trades and verify TP adjustments prevent daily loss breach.
- Check that TP levels are reasonable (not too tight).

## Step 5: Optimize AI Prompt

Adjust the prompt to include more context (e.g., volatility, news events) for better TP suggestions.

## Best Practices

- Use a separate VPS for each challenge account to avoid conflicts.
- Set up alerts (email/SMS) if script stops.
- Regularly review AI suggestions and fine-tune.
- Ensure VPS latency < 10ms to your broker's server.

## Troubleshooting

- **MT5 connection issues**: Restart MT5 terminal on VPS.
- **API rate limits**: Use a queue or batch requests.
- **Incorrect TP values**: Validate AI output with a sanity check (e.g., within 50 pips of current price).

## Conclusion

This AI-powered exit optimizer automates risk management for prop firm challenges, allowing you to focus on trading while the system ensures compliance. With proper setup, you can significantly reduce the risk of blowing your challenge due to daily loss limits.
