## Automated Compliance Report Generator for Prop Firm Audits

### Overview
This workflow automates the generation of compliance reports for prop firm audits by analyzing trade logs (CSV/MT4/MT5 exports) and summarizing findings using LLMs. It checks for rule violations (e.g., max drawdown, lot size limits, trading hours) and produces a human-readable report.

### Prerequisites
- Python 3.8+ installed on a VPS (e.g., DigitalOcean, AWS EC2)
- OpenAI API key with GPT-4 access
- Trade logs in CSV format (columns: Date, Time, Symbol, Type, Volume, Price, Profit, Balance)
- Google Sheets API access (optional for storing reports)

### Step 1: Set Up Environment
1. Launch a VPS (e.g., DigitalOcean droplet, $5/mo) with Ubuntu 20.04.
2. SSH into the VPS and install Python dependencies:
   ```bash
   sudo apt update && sudo apt install python3-pip -y
   pip3 install pandas openai google-auth google-auth-oauthlib google-auth-httplib2 google-api-python-client
   ```
3. Set environment variables:
   ```bash
   export OPENAI_API_KEY='your-api-key'
   ```

### Step 2: Write Trade Log Analyzer Script
Create `analyze_trades.py`:
```python
import pandas as pd
import json

def load_trades(csv_path):
    df = pd.read_csv(csv_path)
    # Convert Date column to datetime
    df['Date'] = pd.to_datetime(df['Date'])
    return df

def check_max_drawdown(df, max_dd_percent=10):
    # Calculate cumulative peak and drawdown
    df['CumulativePeak'] = df['Balance'].cummax()
    df['Drawdown'] = (df['CumulativePeak'] - df['Balance']) / df['CumulativePeak'] * 100
    violations = df[df['Drawdown'] > max_dd_percent]
    return violations

def check_lot_size(df, max_lot=2.0):
    violations = df[df['Volume'] > max_lot]
    return violations

def check_trading_hours(df, start_hour=9, end_hour=17):
    df['Hour'] = df['Date'].dt.hour
    violations = df[(df['Hour'] < start_hour) | (df['Hour'] > end_hour)]
    return violations

def generate_summary(violations_dict):
    summary = {}
    for rule, df in violations_dict.items():
        if not df.empty:
            summary[rule] = {
                'count': len(df),
                'details': df[['Date', 'Symbol', 'Volume', 'Profit']].to_dict('records')
            }
        else:
            summary[rule] = {'count': 0, 'details': []}
    return summary

if __name__ == '__main__':
    trades = load_trades('trades.csv')
    violations = {
        'max_drawdown': check_max_drawdown(trades),
        'lot_size': check_lot_size(trades),
        'trading_hours': check_trading_hours(trades)
    }
    summary = generate_summary(violations)
    with open('violations_summary.json', 'w') as f:
        json.dump(summary, f, indent=2, default=str)
    print('Violations summary saved to violations_summary.json')
```

### Step 3: Create LLM Summarization Script
Create `generate_report.py`:
```python
import openai
import json

openai.api_key = 'your-api-key'

def load_violations(json_path):
    with open(json_path, 'r') as f:
        return json.load(f)

def create_prompt(violations):
    prompt = "You are a compliance officer. Generate a professional audit report based on the following violations:\n\n"
    for rule, data in violations.items():
        prompt += f"- {rule}: {data['count']} violations\n"
        if data['details']:
            prompt += f"  Examples: {data['details'][:3]}\n"
    prompt += "\nProvide a summary, risk assessment, and recommendations."
    return prompt

def generate_report(prompt):
    response = openai.ChatCompletion.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.3,
        max_tokens=2000
    )
    return response.choices[0].message.content

if __name__ == '__main__':
    violations = load_violations('violations_summary.json')
    prompt = create_prompt(violations)
    report = generate_report(prompt)
    with open('compliance_report.txt', 'w') as f:
        f.write(report)
    print('Compliance report saved to compliance_report.txt')
```
