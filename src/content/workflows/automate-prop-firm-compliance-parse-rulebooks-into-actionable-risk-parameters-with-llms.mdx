## Overview

Prop firm rulebooks are dense, often 20+ pages, with critical risk parameters buried in legalese. This workflow uses an LLM (ChatGPT) to parse PDF rulebooks, extract key rules (max daily loss, max drawdown, profit targets, trading hours, etc.), and output a structured JSON checklist. Automation via Make (formerly Integromat) stores the output in Google Drive for easy reference.

## Prerequisites

- ChatGPT Plus (or GPT-4 API access) – $20/mo
- Make account (free tier available)
- Google Drive account (free)
- PDF copy of your prop firm rulebook

## Step-by-Step Guide

### Step 1: Prepare the Rulebook PDF

1. Download the rulebook PDF from your prop firm’s website.
2. If the PDF is scanned, use OCR (e.g., Google Drive’s built-in OCR or Adobe Acrobat) to convert to selectable text.
3. Save the PDF to a dedicated folder in Google Drive (e.g., "Prop Firm Rulebooks").

### Step 2: Extract Text from PDF (Optional but Recommended)

For better LLM performance, extract plain text:
- Use a free tool like **PDFtoText** (online) or Python script with PyPDF2.
- Save the extracted text as a .txt file.

### Step 3: Create a ChatGPT Custom GPT (or Use a Prompt Template)

Create a custom GPT named **"Prop Firm Rule Parser"** with these instructions:

```
You are a compliance automation assistant. Given the text of a prop firm rulebook, extract the following risk parameters and output them as a JSON object:
- max_daily_loss (percentage or fixed amount)
- max_drawdown (percentage)
- profit_target (percentage)
- minimum_trading_days
- maximum_trading_days
- trading_hours (e.g., 24/5 or specific session)
- instruments_allowed (list)
- leverage (e.g., 1:100)
- news_trading_restricted (boolean)
- ea_allowed (boolean)
- scaling_plan (if any)
- consistency_rules (if any)

If a parameter is not found, set it to null. Output ONLY valid JSON.
```

### Step 4: Run the Parsing

1. Open ChatGPT and select your custom GPT.
2. Upload the rulebook text file (or paste the text).
3. The GPT will return a JSON object. Copy it.

### Step 5: Automate Storage with Make

1. Log in to Make and create a new scenario.
2. Trigger: **Webhook** (or schedule daily).
3. Action: **Google Drive – Create a File**.
   - Folder: your rulebooks folder.
   - File Name: `{{timestamp}}_risk_params.json`
   - File Content: paste the JSON from ChatGPT (or use a webhook to receive it automatically).
4. Save and run the scenario.

### Step 6: Use the Risk Parameters

- Reference the JSON file before each trading session.
- Set your trading platform (MT4/MT5) risk limits accordingly.
- Update the file when the prop firm updates its rules.

## Tips for Success

- **Validate Output**: Always double-check critical numbers (e.g., max daily loss) manually.
- **Handle Updates**: Re-run the workflow whenever the prop firm releases a new rulebook version.
- **Scale**: Use the API version of GPT-4 to process multiple rulebooks in batch.

## Troubleshooting

- **Poor OCR**: If the PDF is scanned, use a dedicated OCR tool like ABBYY FineReader.
- **Incomplete JSON**: Adjust the prompt to request missing fields explicitly.
- **Automation Errors**: Ensure Make has proper Google Drive permissions.

## Conclusion

This workflow reduces rulebook review from hours to minutes, ensuring you never accidentally violate a rule. Combine with a risk management dashboard for real-time compliance monitoring.
