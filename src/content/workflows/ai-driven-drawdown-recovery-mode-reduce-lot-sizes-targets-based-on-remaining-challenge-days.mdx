## Overview

This workflow uses AI to monitor your prop firm challenge account and automatically switch to a recovery mode when drawdown exceeds a threshold. It reduces lot sizes and adjusts profit targets based on the number of days remaining in the challenge, helping you avoid blowing the account.

## Prerequisites

- A prop firm challenge account (e.g., FTMO, MFF, etc.)
- TradingView account (free or paid)
- Forex Copier (or similar trade copier)
- Myfxbook account (free)
- ChatGPT Plus (optional, for AI analysis)

## Step 1: Set Up TradingView Alerts for Drawdown Monitoring

1. Log in to TradingView and open the chart for your trading instrument.
2. Create an alert by clicking the alarm clock icon.
3. Set condition to "Custom Formula" and enter:
   ```
   (strategy.equity - strategy.initial_capital) / strategy.initial_capital * 100 <= -5
   ```
   This triggers when drawdown reaches 5%.
4. Set the alert to send a webhook to your automation platform (e.g., Zapier, n8n).

## Step 2: Configure Forex Copier for Lot Size Adjustment

1. Install Forex Copier on your VPS (recommended: AWS EC2 t2.micro, $0.0116/hr).
2. Create a new profile for recovery mode.
3. Set lot size multiplier to 0.5 (50% reduction) and max lot size to 0.1.
4. Link the profile to a webhook endpoint that receives commands from your AI.

## Step 3: Connect Myfxbook for Account Statistics

1. Add your challenge account to Myfxbook.
2. Enable API access and note your API key.
3. Use Myfxbook's API to fetch daily equity, drawdown, and days remaining.

## Step 4: Build AI Logic with ChatGPT (or Custom Script)

1. Create a system prompt in ChatGPT:
   ```
   You are a Forex risk manager. Given account equity, initial balance, drawdown %, days remaining in challenge, and current lot size, calculate:
   - Reduced lot size (proportional to drawdown severity and days left)
   - Adjusted daily profit target (e.g., 0.5% per day if >10 days left, 1% if <5 days)
   Output JSON with 'lotSize' and 'dailyTarget'.
   ```
2. Use ChatGPT API to send account data and receive parameters.
3. Automate this via a script (Python) that runs every hour.

## Step 5: Automate Execution

1. Use a cron job on your VPS to run the Python script every hour.
2. The script:
   - Fetches account data from Myfxbook API.
   - Sends data to ChatGPT API.
   - Receives new lot size and target.
   - Sends commands to Forex Copier webhook to adjust lot size.
   - Updates TradingView alert thresholds if needed.

## Step 6: Monitor and Adjust

1. Check Myfxbook daily for recovery progress.
2. If drawdown exceeds 10%, reduce lot size further (e.g., 0.3x).
3. If days remaining < 3, set daily target to 2% but keep lot size minimal.

## Risk Management Parameters

- Max drawdown: 12% (hard stop)
- Lot size reduction: 50% at 5% drawdown, 70% at 10% drawdown
- Daily target: 0.5% of initial balance when >10 days left, 1% when 5-10 days, 2% when <5 days
- VPS latency: <5ms to broker (use AWS regions close to broker servers)

## Prop Firm Compatibility

This strategy works with FTMO, MFF, and most prop firms that allow EA trading. Ensure your broker supports API trading and that your VPS is whitelisted.

## Conclusion

By automating drawdown recovery with AI, you can save your challenge account and increase pass rates. Adjust parameters based on your trading style and prop firm rules.
