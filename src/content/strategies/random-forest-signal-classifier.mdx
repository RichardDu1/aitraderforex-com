## Random Forest Signal Classifier — Full Analysis

The Random Forest algorithm is an ensemble learning method that combines multiple decision trees to create a robust classification model. It's one of the most accessible ML approaches for forex trading.

### Feature Engineering

Key features used in our implementation:
- Price action features (candle patterns, support/resistance)
- Technical indicators (RSI, MACD, Stochastic, ATR)
- Market microstructure (spread, volume profile)
- Time-based features (day of week, session overlap)
