## Reinforcement Learning Grid Trading — Full Analysis

This strategy combines the classic grid trading approach with modern reinforcement learning to dynamically optimize grid parameters.

### How It Works

The RL agent learns to optimize:
- Grid spacing (distance between orders)
- Position sizing per grid level
- Take profit targets
- Maximum grid levels
- When to pause trading
